## 📌 Project Overview

Forest Fire Detection Using CNN is a Deep Learning project that identifies whether a forest image contains fire or no fire.

The application uses a trained CNN-based image classification model and Streamlit to provide an interactive interface for image upload and prediction.

## 🎯 Project Objectives

- Detect forest fire from uploaded images.
- Classify images into FIRE and NON_FIRE categories.
- Display prediction results and confidence scores.
- Provide a simple and user-friendly web application.

## 📂 Dataset

The dataset contains two categories:

- **FIRE** – Images containing forest fire.
- **NON_FIRE** – Images without forest fire.

👉 **[Click Here to Access the Forest Fire Dataset](https://drive.google.com/drive/folders/1RlBSMNWSl-ns7NsxT5jRDT0nNZiWrqfk?usp=drive_link)**

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- CNN / MobileNetV2
- NumPy
- Pillow
- Streamlit

## ⚙️ Project Workflow

1. Collect the forest fire image dataset.
2. Perform image preprocessing and resizing.
3. Split the dataset into training and validation sets.
4. Train the deep learning image classification model.
5. Evaluate the trained model.
6. Save the trained model.
7. Build a Streamlit web application.
8. Upload an image and predict FIRE or NON_FIRE.

## ✨ Application Features

- Forest-themed user interface.
- Upload JPG, JPEG and PNG images.
- Display uploaded image previews.
- Predict FIRE or NON_FIRE.
- Display prediction confidence percentage.
- Interactive Streamlit application.

## 💻 Installation and Execution

### 1. Clone the repository

```bash
git clone https://github.com/nidigallusandeep-arch/Forest-Fire-Monitoring-Using-CNN.git
```

### 2. Navigate to the project folder

```bash
cd Forest-Fire-Monitoring-Using-CNN
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```
